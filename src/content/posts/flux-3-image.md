FLUX 3 Image 是德国 Black Forest Labs 2026 年 10 月 1 日上线的图像模型，它不跟你拼“随手一画好不好看”，拼的是控制力：画面里每个元素放在哪、多大、长什么样，都能用边界框精确指定。

## 是什么

FLUX 3 Image 是 FLUX 3 多模态家族的图像部分，同一架构还覆盖视频、音频与动作。它的核心设计是“布局即提示词”：你给每个重要元素画一个边界框（bounding box），再用一句话描述整个场景，模型按框出图，元素不会乱跑、不会互相遮挡错位，官方说法是“对每一个像素的最大控制”。模型通过 BFL API 和浏览器 Playground 提供，没有免费套餐，按分辨率按张计费。同家族还有更便宜的精简版 FLUX 3 Image Klein，适合预算有限的批量出图。

![Black Forest Labs 官网首页，FLUX 3 多模态模型主视觉](/images/tools/flux-3-image/home.webp)

## 能干什么

- **边界框排版**：用 JSON 写一个元素表，每个元素有 id、边界框坐标和描述，比如标题放左上、人物放中间、产品放右下，适合海报、杂志跨页、电商主图、拼贴和多格漫画这种“位置不能错”的图。
- **一次改多处且互不干扰**：可以同时改多个框里的内容，比如换背景、换一件衣服、移动一个道具，没动过的部分保持原样，适合反复打磨同一张成图。
- **10 张参考图融合**：一次最多传入 10 张参考图，把多个人物、产品、风格合成一张构图完整的图，不用再一张一张拼。
- **原生 2K 与 4K 输出**：直接渲染到 4K（约 1600 万像素），小字、纹理、人脸细节保留更好，放大做印刷或大屏展示也不容易糊；另有像素级局部编辑，只改框内区域，框外像素不动。
- **为 Agent 而生**：模型原生理解布局与构图，Agent 只要给一句话和宽高比就能自己规划版式，适合接进自动化出图流程。另有商用权重授权，可微调后部署在自己的基础设施上，须联系官方洽谈。

## 免费还是付费

无免费套餐，按量付费，API 与 Playground 同价，1 credit = $0.01，按分辨率分档：

### 768×768（约 0.6MP）

- **单价**：$0.041/张
- **适合**：草稿、快速验证构图

### 1K（约 1MP）

- **单价**：$0.048/张
- **适合**：日常出图、社交媒体

### 1.5K

- **单价**：$0.070/张
- **适合**：细节要求较高的成图

### 2K

- **单价**：$0.100/张
- **适合**：高清成图、印刷小尺寸

### 4K（约 16MP）

- **单价**：$0.607/张
- **适合**：印刷、大屏、精修交付

参考图不额外收费，宽高比不影响价格，但 4K 的价格是 1K 的 12 倍多，出 4K 之前先用 1K 把构图定下来。Playground 提供免费演示入口，但免费额度官网未公开，以页面实际显示为准。精简版 Klein 便宜得多，约 $0.008/张起，4K 约 $0.036/张，画质要求不高时可优先考虑。

## 怎么用

1. 打开 bfl.ai 的 FLUX 3 Image 页面，进 Playground 注册账号并充值 credits。
2. **只想快速出图**：直接写提示词，不画框，模型按文字理解构图出图。
3. **要精确排版**：先画边界框：画布是 0–1000 的网格，每个框写成 [y_min, x_min, y_max, x_max]；再写一段全局描述概括整个场景，并在描述里用元素 id（如 town_1）指代每个元素。
4. **融合参考图**：上传最多 10 张参考图，说明每张图在画面里扮演什么角色，一次生成。
5. **改图**：选中要改的框，重新描述、替换或移动它，其他框不动；也可以一次改多个框。
6. **走 API**：调用 `POST https://api.bfl.ai/v1/flux-3-image`，同一个接口同时负责生成、编辑与多图融合，无需切换模式。

## 国内使用注意

BFL 官网、Playground 与 API 都需要 VPN 才能访问，充值需用海外支付方式（信用卡等），国内银行卡一般无法直接付款，这是国内用户最大的门槛。提示词建议用英文写，布局描述越具体越好，中文提示词的理解效果官网未公开说明，重要成图建议先用英文跑一版。商用方面，API 出图可商用，但开源权重版本尚未发布，Klein 的开源权重采用 FLUX 社区许可证，年收入有上限要求，大规模商用前请读官方授权页。国内平替可选即梦 AI、LiblibAI，能满足日常出图和改图，但做不到 FLUX 3 这种“框住每个元素”的精确排版；如果排版精度是刚需，又不想翻墙，可以先用即梦出图，再进稿定设计或 Figma 手动排版。
