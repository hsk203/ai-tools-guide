## 账号被封，问题可能出在 IP 上

平台判断一个账号靠不靠谱，IP 是第一道关。它会看你的 IP 是不是数据中心 IP、是不是被很多人共用、是不是进过黑名单、是不是跟你的 DNS、WebRTC 泄漏出来的真实位置对不上。任何一项踩雷，账号就容易被标记。

很多人以为"能连上、速度快"就是好代理，其实不是。真正决定账号生死的，是 IP 的纯净度。

## IP 纯净度到底是什么：六个关键指标

### 1. 风控值：越低越干净

风控值（风险分数）是综合评分，越低越好。0–10% 属于极度纯净，30% 以上就要小心，超过 50% 基本就是高危 IP。本文实测的这条香港 IP，风控值只有 **7%**，属于"极度纯净"那一档。

### 2. 住宅 IP 还是机房 IP

这是最关键的区别。**住宅 IP** 是真实家庭宽带分配的地址，归属运营商（比如香港有线电视），平台很难分辨你是在家上网还是在用代理。**机房 IP** 来自数据中心，一查 ASN 就知道是服务器，平台一眼就能认出来，风控直接拉满。

实测这条 IP 的类型是"家庭宽带 IP"，网络类型 Cable/DSL，归属商是 Hong Kong Cable Television Limited（AS9908），是不折不扣的住宅 IP。

### 3. 原生 IP

原生 IP 指这个 IP 段就是归属地 ISP 直接分配的，注册地和实际使用地一致。非原生 IP（比如广播 IP）归属地和实际位置对不上，平台一查就知道有问题。实测这条 IP 标注为"原生 IP"。

### 4. 共享人数：越少越好

一条 IP 同时被多少人用，直接决定会不会被"连坐"。别人用同一个 IP 干了违规的事，平台封的是整个 IP，你跟着遭殃。实测这条 IP 的共享人数是 **1–10 人**，属于"极好"那一档。市面上很多廉价代理一条 IP 共享几百人，封号率自然高。

### 5. 黑名单：必须干净

IP 有没有进过 Spamhaus 之类的黑名单，是硬指标。进了黑名单的 IP，注册账号基本秒封。实测这条 IP 的黑名单检测是"否"，匿名 VPN、机房代理、公共代理也全是"否"。

### 6. WebRTC 和 DNS 泄漏：最容易被忽略的坑

很多人只看 IP 地址，却忽略了泄漏。WebRTC 会在浏览器里暴露你的真实 IP，DNS 会暴露你的真实位置。如果 IP 显示香港，DNS 却显示内地，平台立刻知道你在"伪装"，账号风险大增。

我用 browserleaks.com 测过这条 IP 所在的浏览器环境：WebRTC Leak Test 显示 **No Leak**，Public IP 就是香港的 61.15.49.112，本地 IP 被隐藏，没有泄漏。WHOER 的检测也显示 DNS 在香港，和 IP 位置一致。

## 怎么自己测 IP 纯净度

不用信商家宣传，自己测最靠谱。推荐三个免费工具：

### ping0.cc

- **测什么**：风控值、IP 类型、共享人数、黑名单
- **重点看什么**：风控值越低越好，IP 类型要是"家庭宽带 IP"，共享人数越少越好

### WHOER

- **测什么**：伪装度、DNS、代理检测
- **重点看什么**：伪装度越高越好，DNS 要和 IP 同地区，代理服务器、黑名单要是"否"

### browserleaks.com/webrtc

- **测什么**：WebRTC 泄漏
- **重点看什么**：必须显示 No Leak，Public IP 要和代理 IP 一致

测的时候注意：要在你实际使用的浏览器环境里测（比如 AdsPower 的那个环境），不要在普通浏览器里测——普通浏览器走的是你的真实网络，测出来的是你的真实 IP，没有意义。
