免费 4 核 8G 的云电脑，不用信用卡，Google 或 GitHub 账号登录就能领——InstaBox 上线不到一个月就火了，福利论坛、开发者社区都在传。

先给结论：免费是真的，配置也是真的。但它不是免费 VPS，而是一台给 AI Agent 用的云端工作台。拿它跑 Agent、编译、测试，血赚；拿它当 24 小时在线的小鸡，会失望。能不能用好，取决于你先搞清楚它的三条硬边界。

![InstaBox 官网首页：Cloud Computers for AI Agents](/images/instabox/home.webp)

## 免费档到底给什么

InstaBox 是 InsForge 团队做的产品，入选了 Y Combinator 2026 年春季批次，2026 年 10 月 14 日上线。它的定位很明确：给每个 AI Agent 一台独立的云端 Linux 机器。

免费档的配置，以官方文档为准：

- **1 台机器，4 vCPU / 8 GiB 内存**，实测可用内存约 7.8 GiB
- **20 GiB 持久化存储**（/data 盘），快照和文件合计上限 200 GB
- **5 个快照**，机器暂停、关机、重启后文件都保留，只有删除机器才会清空
- **每月 100 GiB 出站流量**，入站永久免费
- **上传约 50 Mbit/s 上限，下载不限速**

底层是 Firecracker microVM（AWS 同款虚拟化技术），系统是 Debian 13，有 sudo root 权限，Docker 预装。免费档用的是 agent-browser 模板，预装了 Node.js 22、 Bun、 uv、 Go、 Rust、 gcc、 Docker 和 Compose，还有 Claude Code、 Codex，以及一套桌面环境（VNC + Xfce + Chromium 浏览器）。

![InstaBox 免费档：$0/月，1 台机器、4 vCPU / 8 GiB、20 GiB 磁盘、5 个快照、每月 100 GiB 出站流量](/images/instabox/free-plan.webp)

接入方式也不只一种：REST API、TypeScript SDK、命令行（`npx instabox@latest sh` 一行就能起一台机器）、SSH / Mosh、VNC 远程桌面，还能把机器上的端口发布成公网 HTTPS 地址，方便对外演示和测试接口。

## 怎么领

领取地址是 [instabox.sh](https://instabox.sh)，首页右上角 Sign up，用 Google 或者 GitHub 账号登录就行，免费档月费是 $0，不用绑信用卡。

上线初期是要排队的，新账号注册后进等候名单，等 1–3 天收激活码。到 2026 年 11 月 13 日，论坛的说法是已经改成直接领取，不用排队了。不过官方没有发公告，注册时以实际页面为准，如果又出现排队也别意外。

最快的上手方式是装 CLI，一行命令登录并启动一台机器：

```bash
npx instabox@latest sh
```

## 三条硬边界，领之前先看清楚

免费档有三条硬限制，这是它和免费 VPS 最大的区别，领之前必须知道。

**第一，闲置 30 分钟自动暂停。** 免费档的空闲暂停时间固定 30 分钟，不能改。好在恢复很快，不到 1 秒，内存状态也保留，文件不会丢。暂停后只收存储费，免费档不收钱。

**第二，单次最长运行 2 小时，随使用增长至 8 小时。** 官方文档写免费档单次最长 2 小时，用得越多上限越高，最高 8 小时。第三方一周实测也印证了约 8 小时的上限。也就是说，它跑不了需要连续跑几天的长任务。

**第三，没有独立入站 IPv4。** 外部访问只能走官方的 HTTPS 网关或 SSH 网关，没法绑定自己的域名，也跑不了需要 24/7 在线的网站或机器人节点。出口 IP 是共享的美国 AWS 数据中心 IP，干净但明确是机房段，不适合发邮件、也不适合过风控严格的平台。

还有一条要提醒：免费政策随时可能收回。官方自己的说法是 "free until we figure it out"（目前免费，之后再说）。早期 beta 用户曾经有 5 台免费，现在已经缩到 1 台了。重要数据别只放在上面。

## 能干什么，不能干什么

**适合：**

- **跑 Claude Code、 Codex 和自动化 Agent**——这是它的设计用途，两个工具都预装了
- **云端浏览器自动化**——桌面 + Chromium，可以远程桌面接管，让 AI 在云电脑里点鼠标、输文字
- **临时构建和开发环境**——Rust、 Go、 Node 工具链齐全，跑项目、调试、部署、测试都行，不占本地电脑资源
- **看 YouTube、日常上网**——预装的浏览器可以直接访问外网，不少人领来就是为了这个
- **轻量实验**——比如网络实验、爬虫、定时任务、网站监控

**不适合：**

- **建站和 24/7 常驻服务**——没有独立 IPv4，30 分钟暂停，8 小时上限，撑不住
- **游戏**——没有 GPU
- **长期运行的重任务**——最长 8 小时就会断
- **需要独立 IP 发邮件、过风控的业务**——共享机房 NAT IP 会被识别
- **只放生产数据**——beta 期免费政策随时可能收紧，别把重要东西押在上面

一句话总结：拿它当 Agent 工作台和临时开发机，血赚；拿它替代你一年十几美元的小鸡，会失望。

## 和同类免费产品对比

同样打"免费云电脑"主意的产品有几家，区别要分清：

- **Simular Box（box.simular.ai）**：同样是给 AI 用的免费云 Linux 桌面，但所有 Agent 共用一台电脑、走一个 MCP 链接；InstaBox 是每个 Agent 各一台独立 VM。注意：Simular 的免费 beta 已于 2026 年 11 月 12 日结束，不再每天刷新积分
- **Cube（cube.computer）**：持久型云端 Linux 电脑，可按需选规格到 32 vCPU / 64GB；新用户送 $25 免费额度，开放注册不用邀请。更像一台通用云电脑，不是 Agent 沙箱
- **Oracle Cloud 免费套餐**：真正的免费 VPS：2 OCPU / 12GB ARM 实例 + 200GB 存储，有独立公网 IPv4，不自动暂停，适合 24/7 常驻。缺点是新加坡区经常无容量，要长期排队抢

三者定位不同：要独立 Agent 沙箱选 InstaBox，要通用云电脑选 Cube，要 24 小时常驻 VPS 选 Oracle 免费套餐。

## 给中国用户的提醒

官网、文档、控制台都是英文，没有中文界面。云电脑自带的 Chromium 浏览器可以直接访问外网（比如看 YouTube），出口是美国 AWS 的共享机房 IP，用来访问海外服务没问题，但过风控严格的平台（比如部分银行、AI 模型注册）可能被识别为机房 IP。

另外注意服务条款的红线：官方明确禁止把机器用作公开代理、公共 VPN 出口、Tor 出口，或者转发第三方流量的中继，也禁止多账号薅免费额度。个人在云电脑里自己上网、跑 Agent 是合规用途，拿它当"梯子"对外共享属于违规，有封号风险。

InstaBox 的免费 4 核 8G 是真的，也是目前对 AI Agent 场景最慷慨的免费算力之一。但它本质是一台 Agent 工作台，不是免费 VPS。领之前先想清楚你要拿它干什么：跑 Agent、编译、测试、看视频，值得领；建站、挂机、跑长期任务，别指望它。
