Gemini Omni 1.2 Flash 是 Google 在 2026 年 11 月 5 日正式推出的视频生成与编辑模型，一句话就能生成带原生音频的短视频，还能用对话接着改。

## 是什么

Gemini Omni 1.2 Flash（模型代码 `gemini-omni-1.2-flash`）是 Google 的多模态视频模型，定位是“快、能对话、能编辑”。它接在 Gemini API 的 Interactions API 上，也集成在 Gemini 应用、Google Flow 和 Google Vids 里。输入可以是文字、图片或视频，输出是带原生音频的视频，单条 3–15 秒，24 帧/秒，分辨率 360p、720p、1080p、4K，画幅 16:9 或 9:16。它的上一代 1.1 版从 2026 年 12 月 3 日起自动转接到 1.2，按 1.2 的价格计费。Google 同时把 Veo 3.1 预览从 Gemini API 下线，Omni Flash 成了 Google 视频生成的主力路线。

## 能干什么

- **文生视频**：写一段提示词，直接生成带配乐、音效和对白的短片，时长可按整秒在 3–15 秒之间指定，默认 10 秒。
- **图生视频**：上传产品图、插画或照片，让静止画面动起来，适合电商主图和广告素材。
- **对话式编辑**：生成后不用重写提示词，直接说“把弹珠换成蓝色”“换成定格动画风格”，模型在原片基础上改，适合一版多改的广告变体。
- **视频扩展与首尾帧插值**：把已有片段接长，或给定开头和结尾两帧，让模型补出中间的运动过程。
- **多参考一致性**：可同时用人物、产品、风格图和最长 3 秒的动态参考来锁定形象，1.2 这一代主打的就是角色和品牌元素在连续镜头里不“变脸”。不过要注意，Google 称 1.2 在 11 项并排偏好指标上都赢过 1.1，这只是官方自评，第三方盲测排行榜当时还没有 1.2 的成绩。

## 免费还是付费

API 没有免费层，每次调用都按量计费；免费额度只存在于 Gemini 应用、Flow 和 Vids 里，随 Google 订阅走。API 按输出 Token 计费，视频输出 $12/每百万 Token，输入（文字、图片、视频）$1.50/每百万 Token，官方再换算成按秒计价：

| 分辨率 | 每秒价格 | 15 秒一条约多少钱 |
| --- | --- | --- |
| 360p（草稿） | $0.023 | $0.35 |
| 720p（默认） | 约 $0.07 | 约 $1.04 |
| 1080p（上采样） | $0.104 | $1.56 |
| 4K（上采样） | $0.209 | $3.13 |

注意 1080p 和 4K 是上采样得到，不是原生渲染。开通付费层最低预付 $5，约够生成 4 条 15 秒 720p 片段。和同行对比，实测价差很直观：Kling 4.0 的官方 API 约 $0.157/秒（720p），Runway Gen-4.5 是 $0.12/秒且自家模型不带原生音频，需要另外配音；Omni 1.2 在 720p 约 $0.07/秒还自带同步音频，是目前大厂模型里按秒最便宜的一档。它的短板也很明确：单条最长只有 15 秒，做不了长叙事；快速体育动作和复杂物理效果仍是官方承认的弱项。

## 怎么用

1. 打开 Google AI Studio，选 `gemini-omni-1.2-flash` 模型，或在 Gemini 应用 / Flow 里直接用。
2. 写提示词时一次写清场景、主体、运镜、光线和声音，例如“清晨的菜市场，镜头缓慢推进，摊主笑着递出一袋橘子，环境音是市集人声”。
3. 先用 360p 出草稿确认构图和动作，满意后再用 720p 生成正式版，成片需要再升到 1080p 或 4K。
4. 想改细节就接着对话：“把背景换成雨夜”“语速再慢一点”，不用重新描述整个画面。
5. 走 API 的话，用 Interactions API 调用，配合 API Key 集成到自己的工具或工作流里。

## 国内使用注意

Google AI Studio、Gemini 应用和 Flow 在国内都需要 VPN 才能访问，注册需要 Google 账号；API 付费要绑定海外支付方式并预付 $5，国内银行卡一般行不通。提示词用英文更稳妥，中文提示词能用，但复杂指令和否定指令建议写英文。国内平替可以先试即梦 AI 和可灵 AI，中文提示词支持更好，也不用折腾支付。如果只是偶尔做几条短视频，先用 Flow 和 Gemini 应用里的免费额度，别一上来就开 API 按量烧钱。
