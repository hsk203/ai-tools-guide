Schematik 是一句话生成 Arduino、ESP32 硬件项目的 AI 助手，用英文说出想做的东西，它就给出零件清单、接线图、组装步骤和可直接烧录的固件，新手也能从零做出一块能跑的小硬件。

## 是什么

Schematik 定位是“AI 硬件 IDE”，创始人 Sam Beek（前 VEED 成员）想解决的问题是：普通编程 Agent 只会写代码，不懂硬件；新手想做个小装置，要先查数据手册、算引脚、画接线、再调固件，门槛太高。它的流程只有三步：说需求、审方案、动手做。你用一句英文描述想法，它返回一整套可执行的方案，包括完整源码、接线图、零件清单和组装说明，再通过 PlatformIO 直接烧录，或导出后自己改。

它支持 Arduino、ESP32 和 Raspberry Pi Pico 三类开发板。官网项目库里有很多现成例子：语音 AI 助手、AI 伴侣小脑袋、桌面语音助手、植物浇水机器人、$8 迷你游戏机等，用的都是 ESP32、OLED 屏、INMP441 麦克风、MAX98357A 功放这类常见的便宜模块。2026 年 10 月底它还上线了 Preview 功能，可以先在浏览器里用 3D 模拟跑一遍固件，确认没问题再去焊真实电路。

## 能干什么

- **需求变方案**：输入“做一个会说话的桌搭助手”，它会选板子、挑模块、定引脚，输出完整项目。
- **画接线图**：每个模块接哪个引脚、3.3V 还是 5V、共地怎么接，都写得明明白白，并标出容易烧件的坑。
- **给零件清单**：列出每个零件的数量、型号和推荐购买渠道，按清单下单即可。
- **写可烧录固件**：生成 Arduino 固件，处理 Wi-Fi、音频采集播放、AI 接口调用等逻辑，配好 PlatformIO 工程。
- **先模拟再动手**：Preview 在浏览器里模拟 Arduino Uno R3、Pico 或 ESP32 上跑固件，验证逻辑后再买零件、接线。

它和 Cursor、Claude Code 的分工很清楚：后者擅长纯软件，Schematik 擅长“软件加硬件”的完整交付。但它不模拟模拟电路，复杂电路仍需人工复核；AI 给的引脚和代码也可能有错，上电前务必对照接线表逐根检查。

## 怎么用

1. 打开 schematik.io，用一句英文写清想做的东西，越具体越好，比如板子、屏幕、要实现的功能。
2. 审阅它给出的方案：先看零件清单和接线图，确认手头或能买到的型号一致，再看固件逻辑有没有明显问题。
3. 需要时先用 Preview 在浏览器里模拟跑一遍，点一点虚拟按钮，确认交互符合预期。
4. 按清单买零件（ESP32、OLED、麦克风、功放、喇叭、面包板、杜邦线），按接线图接线，断电接线、共地、3.3V 器件别接 5V。
5. 用 USB 线连电脑，通过 Schematik 的 Deploy 按钮或 PlatformIO 烧录固件，填好 Wi-Fi 密码和用到的 AI 接口 Key（别写进公开分享的固件里）。

## 国内使用注意

官网在国内需要 VPN 访问，界面和需求输入都是英文，写需求时用简单英文即可。硬件不难买：ESP32、OLED、INMP441、MAX98357A 这些模块在淘宝、京东都有现货，价格比海外更便宜，引脚定义以模块实物丝印为准。部分语音助手类项目要调 OpenAI 的 Whisper、GPT-4o-mini 等接口，国内直连困难，需要 VPN 和海外 API Key，新手建议先从不联网的项目（如游戏机、时钟、浇水器）练手。国内没有同款“一句话出接线图加固件”的 AI 硬件工具，平替思路是嘉立创 EDA 这类国产硬件平台画板子、查资料，再配合通用编程 Agent 写代码，只是要自己拼流程，没有 Schematik 这样一站式。
